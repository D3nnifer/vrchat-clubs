# vrchat-clubs

A photo gallery of VRChat club event screenshots, published at:  
**https://d3nnifer.github.io/vrchat-clubs/**

## Adding new images

1. Create a folder named `YYYY-MM` for the month (e.g. `2026-03`).
2. Drop your VRChat screenshots (PNG) inside it.
3. Add an `<a>` / `<img>` entry for each new image in `index.html` under the matching month section.
4. Commit and push to `main` — GitHub Actions will redeploy the site automatically.
